## 📢 저장소 이전 안내

**이 저장소(자체 배포 저장소)는 더 이상 운영되지 않습니다.**
V-World QGIS 플러그인은 **QGIS 공식 플러그인 저장소**로 이전되었습니다.

- 기존 저장소로 설치한 플러그인은 QGIS [플러그인] → [플러그인 관리 및 설치] → [설정] 탭에서 삭제해 주세요.
- QGIS [플러그인 관리 및 설치] → [모두] 탭에서 `브이월드` 를 검색해 새 버전을 설치해 주세요.
- 이후 신규 버전은 QGIS 공식 저장소를 통해 자동으로 업데이트됩니다.

자세한 이전 절차는 [`V-World_QGIS_플러그인_안내`](./V-World_QGIS_플러그인_안내) 폴더의 안내 이미지를 참고해 주세요.
(이 저장소로 설치된 플러그인을 실행하면 동일한 안내가 QGIS 안에서도 표시됩니다.)

## ⚙️ 요구사항
QGIS: 버전 3.10 이상
